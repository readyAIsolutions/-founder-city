# Founder City — locked product decisions

1. **Audience: ADULT entrepreneurs first.** Locked. The paying, retention-bearing audience is
   adults building real careers/businesses. Founder City ships for them first.

2. **School/teen edition = a separate configuration, designed now, built later.**
   The game core is audience-agnostic; a future education edition is a *config toggle*:
   - `sandbox=true` → disables real money, payouts, coaches' real fees, external network, voice
     and LLM; fictional economy becomes pure (no cash-out).
   - adds educator/teacher dashboard, curriculum modules, and a Women's Entrepreneurship Academy
     (mentorship groups, women-led networks, leadership dev, case studies).
   - complies with COPPA/age-safety by design (no real-money, gated social, moderated content).
   Building this as a config (not a rewrite) keeps adult-version velocity high.

3. **Principle held firm:** fictional wealth stays strictly separate from real money, real
   investments, and professional qualifications. AI never rewards a player's real expertise from
   game points, and real-money paths stay behind real credentials + human verification.

4. **Real World Missions are the centrepiece** (finite, evidence-based, human-verified rewards at
   the boundary between the game and real life).
